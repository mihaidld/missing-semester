What was the commit message associated with the last modification to the collections: line of _config.yml? (Hint: use git blame and git show).
Show for each line of _config.yml, which commit modified it, then grep line "collections:"
Use awk to keep only the first column containing prefix of hash commit
use xargs to convert STDIN to arg for git show which shows the details of that commit

4. Clone some repository from GitHub, and modify one of its existing files. 
What happens when you do git stash? 
Saved working directory and index state WIP on master: b5534a5 Address link checker failures
The change has dissapeared in working directory, git log still shows latest commit b5534a5 Address link ...

What do you see when running git log --all --oneline? 
0447205 (refs/stash) WIP on master: b5534a5 Address link checker failures
f5840d4 index on master: b5534a5 Address link checker failures
b5534a5 (HEAD -> master, origin/master, origin/HEAD) Address link checker failures
We see references to stashed changes

Run git stash pop to undo what you did with git stash. 
The working directory is updated with stashed change, and change is removed from git log history.

In what scenario might this be useful?
When working on a feature not yet tested so we don't want to commit it yet, but we might need to fetch / push other work
while putting aside work on this feature temporarily and getting back to it later

5. Like many command line tools, Git provides a configuration file (or dotfile) called ~/.gitconfig. 
Create an alias in ~/.gitconfig so that when you run git graph, you get the output of git log --all --graph --decorate --oneline. 
You can do this by directly editing the ~/.gitconfig file, or you can use the git config command to add the alias. Information about git aliases can be found here.
Edit ~/.gitconfig file by adding:
 [alias]
         graph = log --all --graph --decorate --oneline
Or use command:
git config --global alias.graph 'log --all --graph --decorate --oneline'

6.You can define global ignore patterns in ~/.gitignore_global after running git config --global core.excludesfile ~/.gitignore_global. This sets the location of the global ignore file that Git will use, but you still need to manually create the file at that path. Set up your global gitignore file to ignore OS-specific or editor-specific temporary files, like .DS_Store.
git config --global core.excludesfile ~/.gitignore_global
echo ".DS_Store" >> ~/.gitignore_global
