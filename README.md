# MIT The Missing Semester of Your CS Education

This repository is a collation of my solutions for the MIT’s 2020 Missing Semester course exercises from Lecture 1 to 9. (No exercises in Lecture 10 and 11).

## 2020 Exercises:

- Shell Tools and Scripting
- Editor (Vim)
- Data wrangling
- Workflow Command-line Environment
- Git (Version Control)
- Debugging and Profiling
- Metaprogramming (build systems, dependency management, testing, CI)
- Security and Cryptography

## Main takeaways:

- Unix/Linux commands and pipelining
- bash/zsh scripting and configuration
- Virtual/Remote Machine setup and connection
- vim editor, plugins and tmux
- Git/Github
- ssh configuration
- Debugging profilers
- Regular expressions
- Public/Private key encryptions
